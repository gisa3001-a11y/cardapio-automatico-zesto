# Leitor Universal V2 - validacao isolada

Esta branch permanece separada da main. O objetivo deste arquivo e deixar explicito que a V2 ainda esta em validacao controlada e nao deve ser mesclada automaticamente.

A liberacao para main depende de:
- testes offline aprovados;
- bateria real executada;
- revisao do relatorio por plataforma;
- verificacao de produtos, adicionais, imagens, pizzas e precos;
- confirmacao manual antes de qualquer merge.
